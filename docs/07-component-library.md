# 7. Component Library

`AppShell`, `Sidebar`, `Topbar`, `MetricCard`, `StatusBadge`, `CatalogueCard`, `SearchField`, `EmptyState`, `Dropzone`, `ProgressUpload`, `DataTable`, `ConfirmDialog`, `Toast`, and `Skeleton` are product primitives. Components own only visual and interaction state; React Query owns server state and React Hook Form + Zod owns forms.
