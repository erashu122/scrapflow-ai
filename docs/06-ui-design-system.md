# 6. UI Design System

The visual language is deliberately calm: ink/slate surfaces, a precise indigo-to-cyan signal gradient, restrained blur, spacious 12-column layouts and a 10 px radius scale. The default typeface is Inter; numeric KPIs use tabular figures. Motion uses 180–280 ms ease-out transitions, with reduced-motion support.

Tokens: `--bg #F7F9FC`, `--surface #FFFFFF`, `--ink #101828`, `--muted #667085`, `--brand #4F46E5`, `--success #12B76A`, `--warning #F79009`, `--danger #F04438`. Dark mode reverses surfaces without changing semantic colour meaning.
